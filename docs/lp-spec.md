## 落とし穴
- LPの地は #E6F1EC だが、**使い方（`.lp-howto-wrap`）と特徴カルーセル（`.lp-solution`）は白**。使い方は中身が600px幅なので、白は box-shadow＋clip-path で画面の端まで広げている
- LPの地は `#view-home` の #E6F1EC（マイページの四麻と同じ）。ヒーローは地のまま（transparent）
- 画面の下に固定の「はじめる」は置かない（2026-11-04 ユーザーの判断。ボタンが中身と動きを隠すため。入口はヒーローと締めの2つ）
- **LPの動きはHTMLが完成形で、JSが後から動かす**（`initLpMotion`）。動きを減らす設定・JSなしでは完成形のまま。遅れ（--d）付きの transition は動かす瞬間のクラス（`.go`）にだけ付ける（準備で隠すときにも遅れが効いて、2行目以降が消えなかった）
- **CTA自体をtransformで動かすアニメは禁止**（Playwrightの「要素静止待ち」でスモークテストが落ちる。2026-07-19に発生。
  一時はping方式で回避したが、2026-07-28のWalica風シンプル化でCTAアニメ自体を廃止）
- 新機能を追加したらLPの「使い方」と特徴カードも更新すること
- フッターのページ内アンカーは #howto のみ（セッションID誤認防止のためハッシュは8文字未満に保つ）
- LPの文字を置換で差しかえるときは、正規表現の終わりを閉じタグの連続にしない（`</div></div>` で止めたら機能のカードまで消えた・2026-11-04）。差しかえる長さを assert する
- **LPの動きは何度でも**（2026-11-04 ユーザーの指定）: 見えたら進み、上へ戻して要素が画面の下へ出るとさかのぼり、また下へ進むと同じ動きが出る（`initLpMotion` の `replay`。比較・見出しは `.pre` の付け外しと transition、小窓は timer を止めて線を縮める、始めやすさの線はスクロールに連動）。動きを足すときは keyframes でなく transition で書き、戻る形も作る
- **使い方は横にめくる**（`.howto-row`・2026-11-04・1099px以下）: 真ん中の1枚を大きく、次の1枚が見える。矢印と点は機能のカードと同じ部品。1100px以上は4列のまま
- clip-path は `none` との間では動かない。動かすときは完成形も `inset(0 0 0 0)` と書く（グラフが一瞬で出ていた・2026-11-04）
- **推移グラフの左から右への動きは、折れ線と点だけ（`<g class="mc-line">`）をクリップする**（2026-11-05〜）。グリッド線・年月のラベルまで一緒にクリップすると、
  背景まで最初隠れてしまう（ユーザー指摘）。SVGの`<g>`へのCSS `clip-path: inset()` は主要ブラウザで問題なく効く
- **成績の節の5枚は全部、JS関数から生成される本物のHTMLを撮影時に書き出し、index.htmlへ静的に貼り付けたもの**（ライブ描画ではない。
  2026-11-05〜）。`miniSparkHtml`・`renderCircle`・`renderHistoryList`等の出力構造を変えても、貼り付け済みの静的HTMLは自動的には変わらない
  （2026-11-05、mc-lineのラップを関数に入れただけでは#lp-liveの表示が変わらず気づいた）。関数やアプリの見た目を変えたら
  `tools/shoot_lp_live_plan.py` → `tools/splice_lp_live.py` を撮り直すこと（docs/image-tools.md）

# ショート動画の計画（2026-10-27〜）

まじゃすこの広報用の縦型ショート動画（1080×1920・15〜30秒）。**1本の動画を YouTube ショート・TikTok・Instagram リール に同じものを出す**。
目的は、アプリの告知だけでなく、**アカウントそのものの再生数とエンゲージメント（保存・コメント・シェア）を上げる**こと。
そのため、アプリの話をしない回（あるある・ニッチ・初心者の壁）も混ぜ、最後の数秒だけ自然にアプリへつなぐ。

## 作り方
- `python tools/make_short.py [名前]` → `まじゃすこ素材/video/<名前>.mp4`（コミットしない。素材は privateリポジトリ）
- HTMLの1コマずつを時刻を進めながら撮って、ffmpeg でつなぐ（録画ではないので毎回同じ仕上がり）。要: `pip install imageio-ffmpeg`
- 見た目は tools/make_sns_v3.py と共通（淡い緑の地・本物の画面のスマホ・数字のカード・✨）。画面は assets/screens/ のスクショ
- 台本は make_short.py の `VIDEOS` に関数を1つ足す。要素は `at(出る秒, 消える秒, 中身)`、スマホは `phone_at`、数字のカードは `chip_at`、最後は `end_card`
- **音は入れない**。BGMは投稿するときに各アプリの中で、そのアプリが使ってよいと出している曲を付ける（著作権の都合。外の曲を動画に焼き込まない）
- 文字は画面の上〜中央に置く。**下の約300pxと右端の約150pxは、いいね・コメントのボタンと説明文に隠れる**
- 用語ルール（CLAUDE.md）は動画の字幕にも効く（金銭を連想させる語は禁止・「スコア記録」）

## 1本の型（どの種類も共通）
1. **0〜2.5秒＝フック**：大きな文字1つで「自分のことだ」と思わせる（問いかけ・言い切り・数字）。ロゴや挨拶から始めない
2. **本編**：1画面に言いたいことは1つ。3〜4秒ごとに画面を切り替える（止まると離脱される）
3. **最後の4秒＝まじゃすこ**：ロゴ・majasco.jp・「プロフィールのリンクから」。アプリと関係ない回でも必ず付ける
- 長さは15〜30秒。最後まで見られた割合が伸びるので、迷ったら短く

## 4つの柱（ローテーション）
| 柱 | 狙い | 例 |
|---|---|---|
| A 正面から機能・告知 | 使ってみたい人を増やす | 「麻雀の集計、まだ電卓？」・新機能の告知・仲間ページ |
| B あるある（コア層） | 共感→コメント・シェア | 集計係あるある・セット麻雀の夜あるある・三麻派あるある |
| C ニッチ・ストレス | 「わかる」「知らなかった」→保存 | 点数申告で揉める・ローカルルールの違い・チップの数え方 |
| D 初心者の壁 | 保存・フォロー（あとで見返す） | ウマ・オカ・符計算の入口・役の覚え方・点数の数え方 |
- フックの型：「〜してる人、損してます」は使わない（煽りすぎ）。使う型＝**問いかけ**（まだ電卓？）／**数字**（20秒でわかる）／**あるある宣言**（集計係あるある）／**意外**（実はウマは決まってない）
- コメントを呼ぶ終わり方：B・Cは最後に「あなたの卓はどっち？」のような問いを1行入れる

## 操作している画面の動画（2026-10-27〜）
- `python tools/record_play.py [名前]` → アプリ（スタブ・本番に触れない）を台本どおりにタップ・入力しながら画面を撮る。
  出力 `まじゃすこ素材/video/clips/<名前>/`（コマのJPEGと timeline.json）。台本は record_play.py の `PLAYS` に関数を足す
  （`r.tap(セレクタ)`・`r.type(セレクタ, 文字)`・`r.swipe(px)`・`r.idle(秒)`・`r.mark(名前)`）
- 指と、タップのオレンジの波紋は**録画には描かない**。make_short.py の `live_at(出る秒, 消える秒, 録画名)` が30コマ/秒で重ねる
  （画面の録画は1秒に9〜11コマしか撮れないが、指はなめらかに動く）。指は動かしている間とタップの前後だけ出て、止まると消える
- 字幕は録画の `r.mark()` の時刻に合わせる（`m["input"]` など）。**字幕と画面の中身が合っているか必ずコマで確かめる**
  （2026-10-27: 4試合目で順位が変わらないのに「入れかわる」と書いていた → 点数を変えて美咲が逆転するようにした）
- 見本の名前は 健太・美咲・翔・陽菜。仮の名前（A〜D）は録画の中でゲームの設定を書きかえて変える

## 台本（次に作る順。秒は目安）
**S1 先月、勝ってた？（A・操作）** 0〜2.5「先月、勝ってた？ / すぐ答えられる？」→ マイページを開く（タップ）→「通算スコアの推移」→ グラフの10月をタップ →「その月の試合が並ぶ」→ 1つタップして結果が開く →「打った日が、ぜんぶ残る。」→ ロゴ。
録画: 仲間ページの見本のデータ（shoot_lp_screens.py と同じ・名前は置きかえ済み）を入れたマイページ

**S2 いつものメンバーの“今期の1位”（A・操作）** 0〜2.5「いつものメンバーで / 1位は誰？」→ 仲間ページ → 表彰台（1位にズーム気味）→ 成績表タブをタップ →「トップ率もラス回避も」→ 対戦タブ →「あの人には勝ち越してる？」→ ロゴ。最後に「あなたの卓の1位は？」

**S3 電卓 vs まじゃすこ（A・操作）** 画面を左右に分ける。左＝電卓の手順（素点→ウマ→オカ→4人ぶん…の字幕が流れる）、右＝ play-quick の録画。上にストップウォッチ。
「よーいドン」→ 右は点数3つで終わり → 左はまだ2人目 →「この差、毎回。」→ ロゴ。冒頭のフック「集計、何秒かかってる？」

**S4 三麻もいつものルールで（A・操作）** 「三麻派の人へ」→ はじめる →「三麻ではじめる」をタップ → 35,000点持ち・ウマ10-0-10 が出る → 点数を2人ぶん入れて最後の1人は自動 → 順位 →「北抜きもチップも、記録できる」は言わない（できることだけ言う）→ ロゴ

**S5 セット麻雀の夜あるある（B）** 「セット麻雀の夜あるある」→ ①「あと半荘だけ」が3回目 ② オーラスで終電を調べはじめる ③ 点棒の貸し借りが分からなくなる ④ 結局だれがトップだったか揉める →「④だけは、まじゃすこで防げます。」→ ロゴ。最後に「あなたの卓は何番？」

**S6 集計係の1日（B）** 時計の数字が進む：「23:30 対局終了」→「23:31 電卓を渡される」→「23:40 ウマ・オカで止まる」→「23:52 写真をLINEに」→「翌週 だれも覚えていない」→「まじゃすこなら 23:31 で終わり」→ play-quick の終わりの数秒 → ロゴ

**S7 同点のとき、どうしてる？（C）** 「同点のとき、順位どうしてる？」→ 上家取り（起家に近い人が上）／順位点を分け合う、の2つを図で → 「卓によって違うので、始める前に決めておく」→ 最後に「あなたの卓はどっち？」→ ロゴ（アプリの機能の説明はしない。言うなら app-spec.md で確かめてから）

**S8 点棒の数え方（D）** 「点棒、ぜんぶ言える？」→ 1本ずつ出てくる：1万点・5千点・千点・百点 → 「25,000点の配り方」の例 → 「数えるのが面倒なら、点数だけ入れればいい」→ play-quick の入力の数秒 → ロゴ（点棒の色はセットで違うので色の名前は言わない）

**S9 最初に覚える役5つ（D）** 「麻雀を始めたら、まずこの5つ」→ リーチ／タンヤオ／役牌／ピンフ／ツモ（門前で自分であがる）を1つ3秒ずつ、牌の図（tools/make_tile_svg.py）つき →「あとは打ちながら覚える」→ ブログの役一覧へ誘導 → ロゴ。保存されやすい

**S10 ウマ・オカで揉めない方法（C）** 「ウマ・オカで揉めたこと、ある？」→「10-30？5-10？ 返しは30,000？」→「始める前に決めて、全員に見せる」→ まじゃすこのルール設定の画面（スクショ）→「URLで全員が同じルールを見られる」→ ロゴ

## 次に作る台本の候補
- A：仲間ページ（ゲームを集めるだけで通算順位が表彰台に）／総当たり表（あの人に勝ち越してる？）／マイページ（グラフの月を押すと…）／三麻にも対応／チーム戦
- B：セット麻雀の夜あるある（「あと半荘だけ」が3回）／点数を数える人あるある／三麻派と四麻派の違い／雀荘デビューの日
- C：ローカルルール（焼き鳥・赤ドラの枚数）で揉める／トビの扱い／同点のときの順位／「25,000持ち」と「30,000持ち」の違い
- D：点数の数え方（点棒の色）／符計算の入口（20符・30符）／役の覚え方（まずはこの5つ）／ドラの数え方／ノーテン罰符
- **D は点数計算の解説まで**。アプリにつなぐときは「集計はまじゃすこで」まで（点数計算はアプリの対象外。CLAUDE.md）

## 出し方
- 週1本から（日曜の夜）。3つのアプリに同じ動画を同じ日に出す。続いたら週2本へ
- 説明文：1行目に動画のフックをそのまま／2行目に「麻雀のスコア記録アプリ まじゃすこ（プロフィールのリンクから）」／ハッシュタグ3〜5個（#麻雀 #麻雀あるある #セット麻雀 #麻雀初心者 #まじゃすこ）
- 予定と本文は Notion の SNS投稿カレンダー（チャンネル「ショート動画」）

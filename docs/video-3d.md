## 作り方
- 牌の絵: `python tools/b3d/make_tile_tex.py <フォルダ>`（まじゃすこの牌 assets/tiles/*.svg の表の面を PNG に）
- 場面と書き出し: `<bpyの入ったpython> tools/b3d/scene.py --tex <牌の絵> --out <出力> --theme dark|green --cams wide,mid,hand,top,meld --size 720x1280 --samples 64 [--step 0〜5] [--save]`
  - bpy は `pip install bpy`（Python 3.13・約430MB）。この環境は GPU が無いので Cycles の CPU（720×1280・64サンプルで1枚 80〜120秒）。EEVEE は使えない
  - `--step` は鳴きの手順のどこまで進んだか（0=鳴く前／2=晒した／3=取った／4=右端に並べた／5=打牌した）。`--save` で .blend も残す
- 席は 0=手前・1=右・2=奥・3=左。席ごとの中身は「手前の席の座標」で作り、Z軸で90度ずつ回す
- **動きの試し**: `--anim [--fps 12] [--frames 20,24,…]` で「チーの5つの手順」（8秒）を1コマずつ `f0000.png`〜 に書き出す。できたコマは飛ばすので、止まっても同じ命令で続きから。540×960・32サンプルで1コマ約23秒（96コマで約40分）。動画にするのは `ffmpeg -framerate 12 -i f%04d.png`。動きは `anim_pose(t, cam)` に、時刻→位置の式で書いてある（キーフレームは使わない）
- カメラは `CAM`（wide＝会場の引き／mid＝肩ごし／face＝奥の選手の顔のアップ／hand＝手前の選手の目線／top＝真上／meld＝右端の牌のアップ）

## 決まり
- **ユニフォームの形は全チーム共通**（2026-11-13 ユーザーの指定）: 襟付きのポロシャツ（左右の襟の折り返し＋首まわりの帯は collar の色）＋前立てと白いボタン3つ＋半袖（袖は肩から上腕の `SLV`＝58%まで。ひじと前腕は肌）。首の前の横棒は使わない。チームで変わるのは色と柄だけ
- **選手は首なし・頭大きめ**（2026-11-11 ユーザーの判断。首があると、ずれたときに変に見える）。頭は `headroot` にまとめて 1.5倍にし、胴にじかにのせる
- **配色は dark（Mリーグの会場に近い暗い舞台）で進める**（2026-11-11 ユーザーの判断）
- **実在の選手の顔は写さない**。顔は全員同じ作り（黒い目・小さな丸い鼻・少し口角の上がった線の口。白い点＝キラキラは付けない。2026-11-12 ユーザーの判断）。**目だけは4種類から選ぶ**（cast の `eyes`: normal＝ふつう／tare＝タレ目／kiri＝キリッとした目＋まゆ／cute＝ふつうの目にまつ毛3本ずつの、かわいらしい目）。緑の人（席2）はタレ目。髪の色と形・体格・ユニフォームの配色（4色まで）だけで「それらしさ」を出す。名前・チームのロゴ・スポンサー・実物のユニフォームの柄は使わない
- 牌はまじゃすこの牌の絵。横向きの牌は牌そのものを90度回す（絵を別に用意しない）
- **牌は本物の1.2倍で作る**（1.35 は大きすぎた。2026-11-12）（`TS`。2026-11-12 ユーザーの依頼「牌を大きく」）。手牌・河・山の位置は `HP` `HX0` `RP` `RX0` `RY` `WY` `HY` から計算する（数字をじかに書かない）
- **腕は長さを変えない**（上腕 .29・前腕 .27）。ひじの位置は `ik_elbow`（外・後ろ・下へ曲がる）、届かない分は `pose_body` が上体を前に倒す。手は手のひら＋指4本＋親指で、前腕の向きに向く
- 配色（`--theme`）: dark＝暗い会場＋卓の側がオレンジ・マットが緑（AMOS REXX のオレンジを参考にした、まじゃすこの配色）／green＝ふだんのショート動画に近い薄い緑の背景＋白い卓。green は使わない案として残してあるだけ

## 手順の見せ方（2026-11-12 ユーザーの依頼）

- 肩の丸み（`shd`）は上腕と同じ太さで、胴の角の中におさめる。太くして外・上に置くと、肩が盛り上がって見える
- **晒した牌の置き場は、手牌の延長線上の右**（手牌と平行・手前のふちをそろえる・倒していない手牌とのあいだは `GAP`＝2.8cm）。手牌の奥に倒すと、手牌と山のあいだにもぐって見えない（2026-11-12 ユーザーの指摘）。右の隅へは、同じ線の上をすべらせる
- **前置きは選手の目から見る**（手前の選手は消す）。肩ごしや横からだと、手牌が細い線になって読めない。入り・①とのあいだはカメラを動かさず、make_clip.py で絵を重ねてつなぐ（動かすと選手の体の中を通る）
- **髪は頭の下の端より下へ垂らさない**（`HAIR_MIN`）。首が無いので、長い髪・ボブの毛先が胴の中にもぐって「首に埋まって」見えた（2026-11-13 ユーザーの指摘・中田・黒沢・二階堂）。髪の部品は下の端が HAIR_MIN より下なら縦にちぢめる
- **半目は黒目の上を切り落として作る**（肌色のまぶたを重ねると、黒目の後ろにもぐったり、白く浮いたりした）。白い光は黒目より手前に置く（同じ高さだと黒目に隠れて見えない）
- **めくる・取る牌は、伏せた山の中でも絵の付いた牌で作る**（`back` は絵の無い牌。カンドラ表示牌を `back` で作ったら、めくると白い面が出た。山の伏せた牌のうち、嶺上牌＝五索・カンドラ表示牌＝二筒だけ絵を持たせている）
- **手順が終わるたびに、手をどけて牌の真上から見せる間を入れる**（`FREEZE`・`PAUSE`・`pause_k`）。手が牌にのったままのコマで止めると、牌が見えない
- 山の長さ（幢の数）は牌の大きさから計算する。決め打ちの数だと、牌の大きさや山の位置を変えたときに、となりの山と角で重なる
- 上体を倒す量（`pose_body` の k）は .16 まで。.40 だと、大きな頭と肩が左肩の上のカメラをふさいで画面が真っ黒になる。足りない分は腕が少し伸びる
- 卓の上のカメラは左肩の上（x=-.40・y=-.62）。左に寄せすぎる（x=-.50・y=-.52）と手牌を真横から見ることになり、絵が見えない。上家の河へ手を伸ばす間は、見る点を左へ振る（`px`）
- 牌は本物の大きさ（幅24mm）なので、腕を体に合わせた太さにすると牌が全部隠れる。前腕は半径26mm、手は牌の手前がわに置く（`OFF`）
- 手前の選手の真上・目線のカメラは、右腕が画面を縦に横切って牌が見えない。**左肩の上から斜めに見る**と、腕が右から入って手牌の表も見える

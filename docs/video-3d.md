# 3Dの対局の動画（土台・2026-11-11〜）

Blender（bpy）で作る、対局の所作を説明する動画の土台。ふだんのショート動画（tools/make_narrated.py）とは別の作り方。

## 作り方
- 牌の絵: `python tools/b3d/make_tile_tex.py <フォルダ>`（まじゃすこの牌 assets/tiles/*.svg の表の面を PNG に）
- 場面と書き出し: `<bpyの入ったpython> tools/b3d/scene.py --tex <牌の絵> --out <出力> --theme dark|green --cams wide,mid,hand,top,meld --size 720x1280 --samples 64 [--step 0〜5] [--save]`
  - bpy は `pip install bpy`（Python 3.13・約430MB）。この環境は GPU が無いので Cycles の CPU（720×1280・64サンプルで1枚 80〜120秒）。EEVEE は使えない
  - `--step` は鳴きの手順のどこまで進んだか（0=鳴く前／2=晒した／3=取った／4=右端に並べた／5=打牌した）。`--save` で .blend も残す
- 席は 0=手前・1=右・2=奥・3=左。席ごとの中身は「手前の席の座標」で作り、Z軸で90度ずつ回す
- **動きの試し**: `--anim [--fps 12] [--frames 20,24,…]` で「チーの5つの手順」（8秒）を1コマずつ `f0000.png`〜 に書き出す。できたコマは飛ばすので、止まっても同じ命令で続きから。540×960・32サンプルで1コマ約23秒（96コマで約40分）。動画にするのは `ffmpeg -framerate 12 -i f%04d.png`。動きは `anim_pose(t, cam)` に、時刻→位置の式で書いてある（キーフレームは使わない）
- カメラは `CAM`（wide＝会場の引き／mid＝肩ごし／hand＝手前の選手の目線／top＝真上／meld＝右端の牌のアップ）

## 決まり
- **選手は首なし・頭大きめ**（2026-11-11 ユーザーの判断。首があると、ずれたときに変に見える）。頭は `headroot` にまとめて 1.5倍にし、胴にじかにのせる
- **配色は dark（Mリーグの会場に近い暗い舞台）で進める**（2026-11-11 ユーザーの判断）
- **実在の選手の顔は写さない**。顔は全員同じ作り（伏し目の線だけ）。髪の色と形・体格・ユニフォームの配色（4色まで）だけで「それらしさ」を出す。名前・チームのロゴ・スポンサー・実物のユニフォームの柄は使わない
- 牌はまじゃすこの牌の絵。横向きの牌は牌そのものを90度回す（絵を別に用意しない）
- 配色（`--theme`）: dark＝暗い会場＋卓の側がオレンジ・マットが緑（AMOS REXX のオレンジを参考にした、まじゃすこの配色）／green＝ふだんのショート動画に近い薄い緑の背景＋白い卓。green は使わない案として残してあるだけ

## 今の状態と次にやること（2026-11-11）
- できている: 会場・卓・牌・選手4人（首なし・頭大きめ）と、チーの5つの手順の動きの試し（8秒・素材リポジトリ `3d/chi-test.mp4`）。ユーザーの感想はまだ
- 試しで分かった弱いところ（次に直す候補）:
  - 卓の上の場面で牌が小さく、手牌の表の絵が読みにくい → 手順ごとにカメラを寄せる／牌だけ少し大きく作る
  - 右腕がまっすぐな棒に見える（ひじが曲がらない・指が無い）→ ひじの位置を決め直す・手を指つきにする
  - 切った牌のあと、手牌のすき間を詰めていない。ほかの3人は動かない
- そのあと: 声（VOICEVOX）と字幕を今のショート動画と同じ作り方でのせる → リーチ・牌の向き・点棒の受け渡しへ

## まだ無いもの
- 指（手は丸いミトン）・左手の動き・ほかの3人の動き。チー以外の所作（リーチ・牌の向き・点棒の受け渡し）
- 画面の表示（局・持ち点の帯・テロップ）＝書き出した動画に、今の動画と同じ HTML の重ね方でのせる
- 点棒・サイコロ・リーチ棒

## 落とし穴
- 牌は本物の大きさ（幅24mm）なので、腕を体に合わせた太さにすると牌が全部隠れる。前腕は半径26mm、手は牌の手前がわに置く（`OFF`）
- 手前の選手の真上・目線のカメラは、右腕が画面を縦に横切って牌が見えない。**左肩の上から斜めに見る**と、腕が右から入って手牌の表も見える
- 頭を大きくしたので、選手の目線のカメラ（`hand`）は頭の中に入る。頭より前（y > -.55）に置く
- 立てた牌の位置は底が卓の上（z + TL/2）。前は中心を卓の高さに置いていて、半分うまっていた
- 卓の本体の箱がマットより高いと、マットも牌も隠れる（本体の上の面は TOP より下に）
- `transform_apply` は scale だけにする（location まで入れると原点が動き、あとから回した部品が飛ぶ＝えりが卓の上に浮いた）
- 照明のワット数は控えめに（Area 40〜70W）。強いと白飛びして、ノイズ除去で形が溶ける
